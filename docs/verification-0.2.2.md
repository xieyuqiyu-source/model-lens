- `pnpm test:ui`：3 项通过，包含系统减少动态效果开、关两种情况下仍等待退出动画，以及组件移除和动画取消的处理。
- `pnpm package`：TypeScript、Vite、Rust Release 与 macOS 打包通过；构建产物中已无 `prefers-reduced-motion` 关闭规则。
- 已安装 0.2.2，签名校验通过，运行界面显示版本 0.2.2；主次布局切换与弹窗打开、Esc 关闭正常，恢复原来的探查优先和手动模式。
- 系统减少动态效果仍开启，未更改 macOS 设置。未逐帧测量动画时序，未重复本轮未改动的凭证后端测试，也未操作真实账号或请求模型。

仍为 Apple Silicon 本地 ad-hoc 签名预览版，未公证；Intel、Windows 未验收。
