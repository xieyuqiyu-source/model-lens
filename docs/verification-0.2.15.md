# 0.2.15：凭证界面精简与额度缓存

日期：2026-10-12。基于 0.2.14 `96f336b`，按用户界面反馈迭代，保留模型探查与凭证管理功能。

## 变化

- 代理地址与 API Key 统一成 12px 高亮文字复制操作，无悬浮底色/变色和按下缩放；Key 仍只由后端直接复制，前端不接收。
- 全部启停改为独立 Switch，无需勾选；任一可编辑账号启用时点击全部关，全关后点击全部开。全选只服务于批量确认删除。
- 历史按钮只保留图标与无障碍名称，删除停用仍可查询等重复说明；保留错误、未知状态及破坏性操作确认。
- Free 灰、Plus 蓝、Pro 紫共用等级标签，覆盖卡片、探查优先紧凑列表、400×270 菜单栏和模型范围下拉；沿用三套主题令牌。
- 手动刷新后写入独立本地额度缓存；连接/启动读取当前凭证列表后按端口和身份恢复原值、日期时间与错误状态。不自动查询真实额度。未知值与零分开，失败保留旧值。
- 缓存不包含账号字段、认证 Token 或管理/客户端 Key；目录 0700、文件 0600、限长读取与原子替换。身份不足时依赖文件修改时间，仍无法识别则不缓存，防止同名账号替换后误套旧额度。
