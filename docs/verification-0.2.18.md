# 0.2.18：快捷探查历史与三账号并行

基于 0.2.17 `e92ecd7`，2026-10-12。

## 修改

- 快捷探查新增后端共享历史，保留当前应用内最近十条任务及原始采样，包括运行中、失败、证据不足；活动任务不被淘汰。结果图标打开详情，重试使用当前型号并校验原任务和账号身份。
- 最多三个账号并行，每个账号三次采样串行；网络请求释放全局管理锁，第四任务及同账号重复任务被拒绝。隐藏窗口继续运行，退出应用结束。定时额度刷新在探查期间跳过该轮。
- 断开、账号替换和过期任务不能覆盖当前结果；分析超时有明确提示。历史不写磁盘，旧版本未保存的记录无法恢复。
- 算法、58 型号参考库、80% 库内权重显示门槛未修改；不能将库内匹配解释为真实身份认证。

- `browser-probe.py`：生产构建 + CSP 下 WebKit / Chromium 通过，真实本地分析 Worker 与合成采样验证普通探查、部分结果、取消及历史。
