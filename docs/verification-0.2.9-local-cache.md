# 0.2.9 独立分支：本地文件记住管理连接

## 本轮范围

2026-10-11，按用户“去掉钥匙串，直接缓存本地”的最新要求，在 `model-lens-isolated` 的 `codex/isolated-dev` 分支开发，基于 `e3ee7c4`。未操作原始 `model-lens` 工作目录，也未合并其中并行开发的界面调整。

主线已新增 `6ae7776`（统一弹窗下拉焦点阴影并精简探查界面），本机安装的应用版本也已是 0.2.9。本分支保留自己的 0.2.9 版本号，但与主线同版本号的内容不同；这是独立分支产物，未覆盖现有安装，不能按版本号假定二者相同。后续整合时应统一版本号及验证记录。

## 行为

- 移除 `security-framework` 依赖及所有钥匙串读写。新版不访问、迁移、删除旧钥匙串条目，因此首次升级需用户在应用内重新输入一次。
- 成功认证后，将端口和密钥以明文 JSON 保存到 `~/Library/Application Support/io.modellens.desktop/connection.json`；目录 0700、文件 0600，应用不上传或云同步。
- 在同目录创建独占临时文件、写入并同步，再原子替换。失败保留旧记录，正常错误路径清理临时文件。
- 启动只恢复本地连接并读取凭证列表；不刷新额度、不调用模型、不启停 CLIProxy。
- 断开保留记录；“忘记密钥并断开”先删除本地文件，成功后才断开。删除失败明确提示并保留会话。
- 损坏或超大记录返回固定错误，保留原文件；拒绝读取符号链接和非普通文件。错误不包含密钥或文件内容。
- 连接窗口、中文 README 与 AGENTS.md 同步更新。本轮未改变视觉布局，未进行 Figma 文案同步验收。
