# 0.2.29 指纹库独立更新

2026-11-13，基于 0.2.28 `2b3955c`。

- 应用启动后加载本机指纹库缓存并在后台检查上游。模型探查底部显示构建日期、模型数与「立即更新」。校验通过后原子替换缓存，下一轮使用新版。下载、校验或保存失败时继续使用当前库，首次离线可使用内置 58 模型库。
- 更新源为 Fingerpoint Detector 公开数据。Rust 校验下载大小、SHA-256、二进制格式和评分参数，使用 `lmfpd 0.2.0` 在本机评分。探查结果记录所用库版本，账号探查从采样开始保留该版本。每次运行最多保留最近 11 个已加载的更新库版本供历史重算，历史仍可查看原始样本。
- `pnpm check`、105 项 Rust 测试和 25 项界面逻辑测试通过。测试覆盖更新与缓存恢复、相同版本跳过下载、损坏或不兼容数据回退。WebKit 和 Chromium 使用合成 IPC 验证自动采样、手动评分、账号历史、第三方 API、更新状态和失败提示。主探查回归使用生产 CSP。
- `pnpm package` 完成，安装到 `~/Applications/ModelLens.app`。版本为 0.2.29，架构 arm64，构建包和安装副本均通过 `codesign --verify --deep --strict`。旧版备份到 `~/Downloads/ModelLens-backup-before-0.2.29.app`。签名为 ad-hoc，未 Apple 公证。
- 本机新版启动后实际加载上游 2026-11-12 构建的 70 模型指纹库。手动检查显示「指纹库已是最新」。本轮开发与验收未调用真实模型采样。
