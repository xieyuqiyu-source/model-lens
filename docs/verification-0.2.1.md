# 0.2.1 动效与弹层验证记录

日期：2026-10-11。目标：Apple Silicon Mac，保持 09A / 11B 界面风格。

## 本轮改动

- 模型与示例账号选择采用同一套下拉控件，含厂商图标、说明、选中标记、键盘导航、边缘避让与开关动画。
- 不支持 Popover API 时回退原生选择框；读屏标签包含当前值。
- 对话框统一标题、内容和操作区；使用原生 dialog 管理焦点，退出动画完成后移除。
- 主次布局、分段选择、折叠内容、按钮、开关、额度条和提示消息补齐过渡。
- CSS 动画（含遮罩）及 JavaScript 退出动画均支持减少动态效果。

## 验证

- `pnpm test:ui`：2 项通过，验证减少动态效果时立即关闭、正常关闭等动画完成，以及取消动画不触发过期回调。
- `pnpm package`：TypeScript、Vite 与 macOS Release 打包通过。
- 代码审查修复旧 WebKit 回退、选中值辅助技术名称、遮罩动效降级三处问题。
- 未修改凭证管理后端；本轮不重复上一版的 11 项 Rust 测试，不调用真实管理接口、不切换账号、不发送模型请求。

## 尚未验证

本机仍处于锁屏，未安装覆盖运行中的旧版，未进行原生 WebView 渲染、实际键盘／读屏、系统明暗及减少动态效果的 GUI 验收。自动化自检与静态审查不替代实机视觉验收。Intel、Windows、旧 macOS 未验证。

发行包为本地 ad-hoc 签名预览版，无 Developer ID 公证。
