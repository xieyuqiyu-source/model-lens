# 0.1.1 菜单栏外壳修正

- 范围：本机 Apple Silicon / macOS 26.5.2。保持主窗口、凭证布局和只读进程发现边界。
- 使用 Tauri 的 macOS Menu 原生材质、透明 WebView、13px 圆角和系统窗口阴影；内部控件仍为 WebView，不宣称替换成 NSMenu 控件。
- 托盘页面不再铺不透明背景，不产生整窗滚动条；深色模式仅作用于托盘，保留绿色额度条与黑色账号文字。
- Release 打包与 TypeScript 检查通过；本机原生截图确认圆角、四行完整显示、底部操作与无外层滚动条；Esc 收起后返回主窗口。
- 未修改或重新测试进程发现算法；未进行真实模型调用、凭证读写或服务启停。
- 使用系统当前深色外观验收，浅色样式经代码检查，未切换用户系统设置；独立窗口截图不能完整呈现桌面背景透射及系统阴影。多显示器未复测。
- 透明 WebView 启用 macos-private-api，目前仅本地 ad-hoc 签名分发，未作 Mac App Store 兼容性验证。
