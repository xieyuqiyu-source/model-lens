# 0.2.12：CLIProxy 模型目录与自动检测界面

日期：2026-10-11。基于 `ed4fab5` / 0.2.11。用户确认旧版能检测，提出模型列表只见 GPT、移除手动检测、凭证优先按钮覆盖说明三项修改；另明确允许应用通过管理接口取得客户端 API Key，仅在后端使用。

## 实现

- 模型列表改用本机标准 `GET /v1/models`；不再按 Codex/Claude OAuth 或静态原始型号过滤，保留服务返回的厂商、别名、前缀。刷新重新读目录，本应用启用凭证集合变化触发刷新。
- 采样改用 `POST /v1/chat/completions`，最多三次串行、单条用户消息、非流式、无工具；每次重新检查凭证状态及模型可用性。仅自然结束的文本回答参与评分。
- 默认“全部已启用凭证”；可选择“模型范围”筛选某凭证目录。卡片入口改为“探查模型”。范围只是模型筛选，实际账号由 CLIProxy 路由；不会声称固定执行指定账号。
- 只读取专用管理字段：v8 `/config/access/api-keys`，v0 `/api-keys`，使用首个有效客户端密钥；空数组、null 或字段 404 允许不带认证头访问固定模型接口，由服务决定鉴权。密钥不回传 IPC/WebView，不记录、不另存，不读取完整配置或认证文件。
- 普通请求 25 秒，采样 120 秒；保留回环、无代理、无重定向、无客户端重试和 4 MiB 响应上限。错误只返回固定说明/HTTP 状态。
- 两窗口的只读目录请求在 Rust 后端排队等会话锁，消除原先只等 1 秒后永久空目录的问题；采样不排队、不自动重试。
- 移除手动模式、输入框、回答切换及对应状态/样式；旧 localStorage 手动偏好被忽略。
- 去掉说明的负 margin，开始按钮下方留 12px；窄栏文字和刷新按钮可换行。去掉遗留的窄栏隐藏范围规则。
- 版本统一为 0.2.12，更新中文 README、AGENTS 与 DESIGN。

## 边界

- 所有开发采样、额度和凭证写入均用合成 HTTP/IPC；助手未读取真实 API Key 或连接文件，未进行真实模型调用/额度刷新/凭证修改。安装后应用自身按授权恢复连接并读取模型目录。
- CLIProxy 自身的重试、账号选择、提示词改写继续生效，可能影响采样一致性；ModelLens 不改这些配置，也不在失败时重试模型 POST。排名仅为参考库内相似度。
- 其他工作树已有新增凭证/额度开发改动，本轮不合并、不覆盖、不快进，后续按用户通知处理。
- 当前只验证本机 Apple Silicon；ad-hoc 签名，未公证。
