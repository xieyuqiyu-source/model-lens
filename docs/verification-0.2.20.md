# 0.2.20：CPA 独立启动、安装和编译更新

2026-10-14，基于 0.2.19 `dc3f68b`。

## 变更

- 更新入口改为“更新并重启”：安全快进拉取、编译到临时程序，完成编译后才停止旧服务。切换失败尝试恢复旧程序与配置，恢复失败明确保留备份路径。源码不自动回退。
- 本机 CLIProxy 弹窗在检测左侧增加启动/重启，支持选择已发现目录、明确端口；占用端口的进程不匹配时拒绝停止。
- 首次接管允许正常停止原 dev 启动器及 CPM，此后 CPA 独立运行；保留配置、认证目录与同源管理页，不创建开机服务。
- 安装从官方 GitHub 克隆，路径支持原生文件夹选择与手填；预检已有进程和目录，目标原子落地且不覆盖。安装记录在落地前登记，缓存失败不留下无法操作的完整安装。
- 新安装生成本地随机密钥，连接保存成功后删除 0600 的临时安装连接记录；保存失败可通过再次启动重试。既有服务密钥不从配置中读取。
- 全局任务互斥、跨窗口进度、关闭面板继续。更高版本的共享结果清除旧本地反馈，避免其他窗口的新失败被旧成功提示掩盖。
