# 0.2.28 手动探查与本地评分

2026-11-12，基于 0.2.27 `ddda723`。

- 模型探查可切换自动检测和手动检测。手动模式按序号复制提示词、粘贴对应回答，在本机使用同一个 Web Worker 和参考库分析，并保存到本次会话的检测历史。
- 手动评分无需连接模型服务。一份或两份有效回答可查看参考库排名，三份有效回答且校准可用时显示库内置信度。切换模式保留回答，更换提示词清空本轮草稿。
- `pnpm check`、103 项 Rust 测试、25 项界面逻辑测试通过。WebKit 和 Chromium 的生产构建回归覆盖自动探查、第三方 API、主窗口与菜单栏焦点，以及手动模式的离线复制、对应回答粘贴、校验、部分与完整评分、历史和更换提示词。手动流程未触发模型目录或采样调用。未调用真实模型。
- `pnpm package` 完成，构建和本机安装副本通过 `codesign --verify --deep --strict`。安装到 `~/Applications/ModelLens.app`，版本 0.2.28，架构 arm64。旧版备份到 `~/Downloads/ModelLens-backup-before-0.2.28.app`。签名为 ad-hoc，未 Apple 公证。
