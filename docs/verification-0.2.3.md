# 0.2.3 主次切换性能验证

日期：2026-10-11。保持两栏比例、09A 样式与 300ms 过渡时长。

## 改动

移除两处 Grid 列宽过渡。切换时同步提交最终 React 布局，交由 View Transitions 动画呈现两个面板快照，避免真实文字和卡片每帧跟随宽度变化重新排版。快照按原尺寸裁切，标题栏保持实时交互。快速反向点击跳过旧动画，并阻止过期更新覆盖最新选择；结束及卸载时清除临时状态。不支持该 API 的旧 WebView 使用短淡入。

实现依据：[WebKit Safari 18 View Transitions](https://webkit.org/blog/15865/webkit-features-in-safari-18-0/)。应用动画继续独立于系统减少动态效果，不修改系统偏好。

## 验证结果

- `pnpm test:ui`：6 项通过，覆盖原有弹窗关闭、系统偏好独立、快速反向切换、旧动画完成不清除新动画、卸载取消与兼容回退。
- `pnpm package`：TypeScript、Vite、Rust Release 打包通过；安装后 ad-hoc 签名校验通过。
- Chrome 本机开发页面，同一窗口、自动模式、未连接凭证，同方向“凭证优先 → 探查优先”各采集一次 Performance 指标：

| 指标 | 原列宽过渡 | 面板快照过渡 |
| --- | ---: | ---: |
| LayoutDuration 增量 | 47.744ms | 4.179ms |
| RecalcStyleDuration 增量 | 15.372ms | 16.832ms |
| LayoutCount 增量 | 39 | 47 |

新方案的快照伪元素仍有布局，因此次数没有减少；主要改善是每次布局不再涉及真实面板内的文字和卡片。这是单次开发页面对比，不代表稳态基准、原生 WebKit 帧率或真实大量账号负载。

- 浏览器连续三次反向点击后最终选择正确，无控制台 warning / error；结束后没有活动动画或遗留 workspace-transitioning 标记。
- 本机已安装并运行 0.2.3；原生窗口可切换到凭证优先再返回探查优先，手动模式保持，结束状态正常。
- 已恢复用户原来的探查优先与手动模式，关闭临时浏览器页和开发服务器。
