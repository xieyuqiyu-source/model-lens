# 0.2.21：CPA 明确启停、路径折叠与命令日志

2026-10-14，基于 0.2.20 界面精简提交 `5992524`。

## 变更

- 本机服务弹窗按所选 CPA 的实际进程显示“关闭 / 启动”，取消此处重启行为。请求携带预期 PID，执行前再次核对发现结果与端口所有者；进程变化时不操作。
- 关闭发送正常退出信号，等待旧 PID 真正消失且端口释放；不会在关闭后启动。原 dev 启动器托管时按已有授权停止它及附带 CPM。
- 关闭成功断开同端口管理会话、保留连接文件；启动恢复该端口的已存连接和额度缓存，不切换其他端口。主界面“更新并重启”保留原编译升级流程。
- 去掉工具栏多余上边距，统一区块间距；地址默认折叠，保留程序名和进程状态。
- 下方命令日志显示时间、受控命令步骤和结果，本次运行最多保存 100 条，关闭弹窗后保留、跨窗口同步；忙碌拒绝同样记录。不读取原始 CPA 日志、密钥或环境，不持久化这些操作日志。

## 验证

- `pnpm test`：91 项 Rust 测试全部通过。生命周期回归覆盖仅启动/仅关闭、重复启动不重启、PID 变化拒绝、释放端口后延迟退出、停止模拟 dev 与附带进程、升级失败恢复和外部端口保护。
- 同端口连接恢复回归检查其他端口记录不会连接；额度缓存回归覆盖 disconnect 清空 records 后恢复周期、等级和剩余重置次数。日志测试覆盖顺序、100 条上限、追加日志不覆盖活动任务状态。
- `pnpm test:ui`：25 项通过；`pnpm check` 通过。
- WebKit/Chromium 合成 IPC 验证关闭→启动切换、预期 PID、按钮顺序、路径折叠、工具栏间距、关闭重开日志保留、手填/选择目录、安装阻止及跨窗口结果。分组与 CPA 动作回归检查请求被拒绝后共享错误可见。
- 独立代码复核完成，修复关闭后启动遗漏额度缓存、请求拒绝被旧结果掩盖及端口先释放时过早报告关闭的问题。
- 所有进程与命令行为仅用临时模拟服务验证，未停止真实 CPA、启动器或 CPM；没有真实凭证写入或采样。
