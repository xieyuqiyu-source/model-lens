# 0.2.0 凭证与额度接入验收

日期：2026-10-11。本机 Apple Silicon，macOS 26.5.2。

## 已验证

- TypeScript 检查、Vite production build、Rust Release 应用打包通过。
- 11 项 Rust 测试通过（5 项进程发现 + 6 项管理/额度测试），HTTP 测试只连接临时回环模拟服务。
- 管理测试覆盖：列表白名单输出不含 account/Token/path；重复身份拒绝；v8 404 后兼容 v0；错误不回显上游响应；外部开关变化阻止写入；写入失败后重新读取、不自动重试；固定额度 URL、指定 auth_index 和 Token 占位符；百分比转换、缺失字段、月度窗口排除。
- 与本机 CLIProxy 源码的列表、状态变更及 Codex/Claude 额度调用契约核对一致，独立代码审查无阻断项。
- Release 应用 ad-hoc 签名检查通过；0.2.0 安装包已生成。
- App 图标以 SVG 绘制，PNG 经过视觉检查，生成包含标准尺寸的 ICNS 和单色菜单栏模板。

## 当前未验证

- Mac 锁屏导致原生应用替换和交互验收暂停；未将源代码检查称为实机操作成功。
- 未读取用户已有管理密钥、认证文件或账号内容。真实服务连接需要用户在应用内输入管理密钥；没有切换真实账号或发起真实额度请求。
- 原生双窗口同步、长列表滚动、连接表单和错误展示仍需解锁后的交互验收。
- Intel Mac、Windows、远程服务、其他厂商额度、JSON 导入及真实模型检测不在本轮交付范围。

## 已知限制

- 管理密钥仅在本次进程内存中，退出后需重新输入。
- 全部额度刷新串行且每次请求超时 25 秒；刷新期间其他管理操作禁用，本版没有独立取消按钮。
- 应用未做 Developer ID 签名或 Apple 公证。
