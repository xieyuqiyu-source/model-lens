# 0.2.8 弹窗焦点边框修复

## 行为与原因

WebKit 在鼠标打开原生 dialog 时，会给自动聚焦的关闭按钮匹配 `:focus-visible`；恢复已有焦点时也可能留下同类边框。应用现在区分鼠标与键盘操作：鼠标操作不绘制非文本控件的自动焦点框，键盘导航保留原有焦点样式，输入框仍显示输入焦点。主窗口和菜单栏共用此规则，支持 macOS Option+Tab。

弹窗关闭动画结束后，在组件卸载前调用原生 `close()`，使键盘焦点可靠回到打开弹窗的入口。继续使用原生模态约束、Esc 与遮罩关闭，不修改已确认的布局、主题与动画。属于交互缺陷修复，本轮不改 Figma 设计稿。
