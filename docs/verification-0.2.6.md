# 0.2.6 主题与明暗模式验收

本轮只调整外观与可访问性，不修改凭证管理协议或模型检测逻辑。

## 实现范围

- 默认翡翠绿，新增海湾蓝、鸢尾紫；三套方案均包含浅色与深色语义颜色。
- 主窗口和菜单栏均可选择浅色、深色或跟随系统；偏好保存在本机，两个窗口同步。
- 背景、文字、按钮、下拉框、弹窗、焦点、额度条统一使用主题变量。
- 隐藏滚动条但保留滚动，凭证列表支持键盘聚焦与滚动。额度条上的账号文字随填充区域使用不同前景色。
- 状态色保持独立，不把蓝色或紫色主题误用为成功、警告或错误含义。

## 自动检查

- `pnpm test:ui`：15 项通过，包含偏好解析、非法值回退、模式解析以及六套颜色组合的对比度检查。
- `pnpm test`：11 项 Rust 测试通过。
- `pnpm package`：TypeScript 检查、Vite 构建与 macOS ARM64 打包通过。
- `codesign --verify --deep --strict`：本机安装包签名校验通过。仍为本地临时签名，未进行 Apple 公证。
- 对比度检查目标：普通文字 4.5:1，必要控件边界、焦点与额度填充相对轨道 3:1；这不是完整的 WCAG 合规认证。

依据：[WCAG 2.2 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

## 界面检查

- 浏览器使用真实组件和合成账号数据检查三套主题的浅色、深色主窗口，以及 400×270 菜单和紧凑外观弹窗。
- 长列表验证无可见滚动条；键盘 End 可滚到列表底部，Home 可返回顶部。
- 本机安装并运行 0.2.6，检查主窗口设置入口、深色与浅色切换，以及三个配色选项。
- 主窗口选择深色海湾蓝后，菜单栏设置显示相同选中项；菜单栏改为浅色鸢尾紫后，主窗口同步显示相同选中项。最后保留浅色翡翠绿。
- 跟随系统的解析逻辑已自动测试；未为验收修改用户 macOS 全局外观设置。
- 独立代码复核未发现阻断问题；已将深色厂商图标反转限定到图片，避免未知厂商 SVG 的继承颜色被再次反转。
