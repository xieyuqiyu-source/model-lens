# 0.2.11：模型探查与凭证管理合并交付

日期：2026-10-11。主线基于 `330abe8`，合并模型探查 `7b417c1` 与独立凭证管理 `7bed2bd44071017c92e4c60c38132ffbe9ce7823`。用户确认两侧完成后授权合并、提交、推送和本机安装。

## 保留的功能

- 探查：DSH 锁定的 LM Fingerpoint Detector 六份上游文件逐字保留，58 个参考模型；Codex/Claude OAuth 三次串行采样，原始模型白名单、手动三回答、部分排名、校准概率、详情与窗口内十次历史。只在点击开始时请求模型，不自动重试。
- 凭证：停用/启用账号手动查询额度，单个 JSON 文件/粘贴导入，确认删除独立文件；保留导入同名/Unicode 检查、删除身份变更检查、写后核实与失败不重试。
- 公共请求层：同时保留 query 编码、v8/v0 路由、禁止代理/重定向/自动重试、204 空响应，以及普通请求 25 秒和采样 120 秒超时。
- “单独检测”传入当前卡片的凭证 ID 并进入自动模式，不自动启动；停用或无法确认 OAuth 的凭证不可发起自动检测。
- 0.2.10 的本地连接文件、主题、焦点阴影、两行回答、折叠栏不高亮及动效保持。
- package.json、Cargo.toml、Cargo.lock、Tauri 配置和界面版本统一 0.2.11。
