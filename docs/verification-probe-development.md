## 已接入

- 原样复用 DSH 已锁定的 LM Fingerpoint Detector：挑战生成、核心特征、排名算法、58 模型参考库、校准参数与 MIT 声明。六份文件哈希与 DSH 记录一致，详见 [来源清单](../src/features/probe/vendor/UPSTREAM.md)。未修改 DSH 插件、宿主或配置。
- 自动检测按已启用且明确 `account_type=oauth` 的 Codex / Claude 凭证读取目录，使用凭证模型与原始模型定义的交集。通过 CLIProxy 管理代请求接口指定 `auth_index`，固定第一方目的地，由服务替换 `$TOKEN$`；不下载认证文件、不读取 API Key 配置、不将密钥发给前端。
- 直接采样原始模型，不应用 CLIProxy 的别名、前缀、自动路由或请求改写。如果别名恰好与真实型号同名，按该原始型号解释；不是通过别名回溯实际路由。
- 每份为独立用户消息，无对话历史、工具或附加系统提示；Codex 的 instructions 为空，仅在原始定义声明时选用最低支持的推理档位；Claude 未开启思考模式。最多串行三次模型请求，不自动重试。请求前重新核实凭证启用状态和模型是否仍可用。
- Codex 支持 JSON 与 SSE 完成快照；不把增量和完整块重复相加。Claude 只采集文本块。非自然结束、错误、数字不足及异常分布不参与评分；错误体和响应头不投影到界面。
- 手动模式三份回答共用默认两行输入框，以序号切换；提示词原文可复制，不发模型请求。局部有效样本可排名，三份有效且校准匹配才显示库内概率；不声称型号认证。
- 本地 JSON 共约 32.5 MB；分析时才由 Web Worker 加载、核验 SHA-256 并评分，结束后释放，不连接检测网站。CSP 仅增补 self 以读取随包数据，不开放外部模型域名给 WebView。
- 原始采样详情、排名与导出；本窗口内最近十次分析历史，不持久化回答或账号记录。已有自动/手动与模型偏好继续保存。
- 取消阻止后续采样和评分；阻塞式管理代请求已经发出时不能撤回，上游可能继续计费，界面等待该请求返回或 120 秒客户端超时。只读模型目录遇到两窗口管理锁竞争时最多重试两次，模型采样绝不自动重试。

## 检查结果

环境：Apple Silicon / macOS 26.5.2，Node 24、Rust 1.89。

- `pnpm test`：27 项通过，其中 7 项探查后端测试；覆盖固定目的地、选定凭证、自然结束、SSE 不重复、错误脱敏、旧版路由与查询编码、停用/缺失模型零 POST、API Key/未知类型零 POST、别名不作为原始 ID 直发。
- `pnpm test:ui`：20 项通过，其中 5 项探查测试；覆盖六份文件哈希、与 DSH 固定样本排名/概率对照、部分结果、校准失配、无效输入、逐条采样、失败停止及取消。
- `pnpm check`、`pnpm build`：通过。生产构建包含本地 Worker 与两份原样 JSON 数据。
- `tests/browser-focus.py`：WebKit / Chromium × 主窗口 / 菜单栏四组通过，保留弹窗、下拉、键盘焦点、六套主题及两行高度回归。模型与凭证选择改为真实目录空态后同步调整测试定位。
- `tests/browser-probe.py`：WebKit / Chromium 两组通过，合成 IPC 覆盖三个有效样本、第二次请求失败保留部分结果、取消、三份手动回答、历史、重置和 Worker 真实本地计算。
- 同一探查浏览器集成测试在生产资源预览与应用 CSP 下再次通过，验证资源路径、哈希校验及 Worker 加载；不等同于已安装 Tauri 原生环境验收。
