# 0.2.7 本机管理连接持久化

## 行为

首次成功连接本机管理接口后，端口与管理密钥一起写入 macOS 本地钥匙串固定条目。读取、写入和删除均显式设置 `synchronized=false`，不启用云端同步。启动时在 Rust 管理会话锁内恢复一次，主窗口和菜单共用同一连接；密钥不返回 WebView、不填回输入框。

断开保留存储记录，忘记会先删除记录再清空会话；删除失败保留连接并报告错误。新密钥认证失败不覆盖旧记录。保存失败保留当前可用会话并提示，后续启动仍使用旧记录（若有）。启动时服务不可用不删除记录，可在连接窗口重试。

## 验证

- Rust：16 项普通测试通过，覆盖成功保存、重启后恢复、忘记、认证失败保留原记录、恢复失败保留重试能力、保存与删除失败，以及快照不含密钥。
- 显式运行 `cargo test --manifest-path src-tauri/Cargo.toml keychain_roundtrip -- --ignored`：1 项本机钥匙串测试通过。使用每次独立命名的测试条目与合成密钥，验证创建、读取、覆盖、删除、再次删除；不访问实际用户连接条目。
- `pnpm test:ui`：15 项现有界面逻辑测试通过。
- `pnpm package`：TypeScript、Vite 与 macOS ARM64 打包通过；安装到本机后，版本显示 0.2.7，连接窗口显示仅在本机记住的说明，端口与密钥输入可用。
- `codesign --verify --deep --strict`：安装包校验通过。
- 独立代码复核发现的无保存记录误报重连成功、初始化失败持续禁用控件均已修正。

## 验证边界

真实密钥由用户在新版应用内输入，助手未读取或代填。本轮未切换真实账号、导入凭证、刷新真实额度或调用模型。钥匙串读写和恢复流程分别通过本机测试条目与模拟管理服务验证；真实用户连接的跨版本自动恢复尚待用户首次保存后使用确认。

目前应用使用本地临时签名，更新后 macOS 可能要求允许访问钥匙串；持久化记录仍在本机，通常无需再次输入管理密钥。稳定 Developer ID 签名跨版本升级、Mac Intel 与 Windows 尚未验收。
