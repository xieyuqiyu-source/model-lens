# 0.2.5 菜单栏真实数据状态与布局

## 修正

- 未取得额度的凭证使用中性空条，避免浅色底被误认成满额度；周期只在有数据时展示。
- 单账号额度异常显示行内图标和底部异常数量，不再误报整个连接失败。
- 紧凑列表稳定地将启用账号排在前面，不改变实际开关或原始列表顺序。
- 保持 400×270 面板，调整行距、滚动条和列表内边距，初始视图完整显示四行。
- 原生 Menu 材质仍随系统明暗与桌面背景变化；本次未修改原生窗口材质。

- 8 项 UI 自检通过，包含异常分类与稳定排序、不修改输入数据。
- TypeScript、Vite 与 Release 应用打包通过；应用签名校验通过。
- 用 8 个合成账号在 Chromium 中检查 400×270 浅色和深色预览：有额度、未知额度、停用、单项失败均可区分。

- 临时预览入口已移除，合成截图不含真实账号。
