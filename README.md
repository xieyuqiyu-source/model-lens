# ModelLens · 模型透镜

一个面向个人使用的模型探查桌面工具，计划兼容 Windows 与 macOS，提供完整窗口及菜单栏／系统托盘入口。

**当前处于需求讨论阶段。仓库仅包含项目说明，尚未开发客户端，没有可运行程序或安装包。**

## 产品定位

轻量、简单、直接。由项目所有者提出需求、决定界面设计，逐步确认功能后再实现。不搭建额外云端服务，不默认增加账号系统或复杂管理功能。

## 已确认的方向

- 项目名称：ModelLens；中文名称：模型透镜。
- 独立目录、独立 Git 仓库，与 DSH 插件项目分别维护。
- 目标平台：Windows、macOS。
- 提供漂亮、易用的桌面界面，并支持 macOS 菜单栏与 Windows 系统托盘。
- 先讨论产品与设计，再开始开发。

## 待确认的首版范围

以下为讨论中的方案，并非已经实现的功能或最终承诺：

| 功能 | 设想 |
| --- | --- |
| 手动检测 | 复制三条检测提示词，粘贴任意外部模型的对应回答，用本地参考库分析 |
| 自动检测 | 配置模型接口地址、密钥和模型，自动采样并分析 |
| 结果展示 | 展示参考库内候选、排名和适用时的校准置信度，支持复制结果 |
| 快捷入口 | 从菜单栏／系统托盘打开检测面板、查看最近结果或进入完整窗口 |

第一版暂不计划迁入 DSH 插件的 CPA 账号管理、余额和糖果测试。仍需决定以完整窗口还是菜单栏小面板为主要入口，以及界面样式、历史记录保存范围和技术栈。

## 与现有 DSH 插件的关系

本项目由已有的 [DSH 插件项目](https://github.com/xieyuqiyu-source/dsh-dev) 讨论延伸而来。本次仅建立独立仓库，未复制插件源码、检测库或发布资产，也未修改 DSH 宿主及其安装配置。

现有插件的本地检测核心可作为后续复用基础；自动采样目前依赖 DSH 模型服务，独立客户端需要另行接入。正式复用上游算法或数据时，应保留许可证、来源、版本及校验信息。

## 数据与检测边界

- 计划在本地完成指纹分析；是否保存输入及历史记录，待需求确认。
- 自动采样会访问用户配置的模型服务，可能产生该服务的调用费用；手动模式下的外部采样费用由外部服务决定。
- API Key、令牌、真实凭证、个人测试记录不得提交到仓库。
- 检测只能比较参考库内的相似候选，不能证明模型身份；库外模型也可能得到高置信度的库内候选。
