# ModelLens · 模型透镜

一个轻量的 macOS 模型探查与 CLIProxy 凭证管理客户端。主窗口负责详细操作，菜单栏提供紧凑的凭证与额度入口。

**当前版本：0.2.11。** 已统一整合两工作树：基于 DSH 指纹库的自动采样与手动分析，以及 JSON 凭证导入、确认删除和停用账号额度查询。保留 0.2.10 的本地连接持久化、焦点阴影、两行回答和现有主题。验证见 [0.2.11 交付记录](docs/verification-0.2.11.md)。

**独立分支新增（待合并发布）**：xAI/Grok、Gemini CLI 与 Antigravity 额度查看，Grok 图标及 Gemini 凭证类型图标映射。基于 0.2.11 开发，不代表已替换本机安装版；验证与范围见 [新厂商额度记录](docs/verification-provider-quota.md)。

## 模型探查

本轮沿用 DSH 已锁定的 LM Fingerpoint Detector：三组独立整数挑战、58 个模型参考库与原始校准参数。数学内核与数据不重写，不访问检测网站。

- **自动检测**：连接管理接口后，选择已启用的 Codex / Claude OAuth 凭证及原始模型，点击开始才发出最多三次串行采样，消耗对应模型额度。只显示凭证目录与厂商原始模型定义的交集；直接请求原始模型，不应用 CLIProxy 的别名、前缀、路由或请求改写。无法确认 OAuth 类型的凭证不会被发送到官方接口。
- **手动检测**：切换“回答 1 / 2 / 3”，复制各自提示词，在外部模型的全新对话中分别采样后粘贴；输入框默认两行。点击“分析输入”只在本地计算，可使用一个或两个有效回答。
- **结果**：显示参考库内前三名；三份有效回答且校准匹配才显示库内置信度，一两份只显示排名。置信度是参考库内的相对概率，不是模型身份认证；库外模型不能据此确认身份。
- **详情与历史**：保留本轮提示词、回答、结束状态、服务返回型号和耗时。结果可复制；窗口内保留最近十次成功分析，退出后不保存回答或账号记录。
- **错误与停止**：无效回答不充作成功；模型请求失败后停止后续采样，已有有效回答可作部分排名。不会自动重试模型请求。停止按钮阻止后续请求和评分，已交给服务的当前请求可能继续执行/计费，界面等待其返回或超时。

实现与合并注意事项见 [探查开发验证](docs/verification-probe-development.md)。API Key / 网关凭证、其他厂商自动采样、模型别名反解、真实账号兼容验证尚未包含；这些模型可使用手动检测。凭证卡片的“单独检测”会选择该账号并进入自动模式，仍需点击开始才采样。

## 系统要求和安装

当前仅交付并验证 **Apple Silicon Mac**；构建目标最低 macOS 13，本机验收环境为 macOS 26.5.2。Intel Mac、Windows 尚未交付。

从源码构建后，应用位于 `src-tauri/target/release/bundle/macos/ModelLens.app`。将它复制到用户“应用程序”目录即可运行。发行版包含前端资源，不需要运行 Node.js 或开发服务器。

当前为本地 ad-hoc 签名预览版，尚无 Developer ID 签名、公证和自动更新。透明 WebView 使用 Tauri `macos-private-api`，目前不以 Mac App Store 分发为目标。

## 首次连接

1. 使用原来的方式运行 CLIProxy。
2. 打开 ModelLens，顶部状态会自动发现进程；点击状态可查看记住的服务位置。
3. 点击设置或凭证区域的连接按钮，填写 **本机管理端口**（默认 8317）与 **CLIProxy 管理密钥**。这不是厂商 API Key。
4. 点击“连接并读取列表”。成功后凭证区域显示真实账号；列表为空与连接失败分别展示。
5. 点击“刷新额度”查询单个凭证，或“刷新全部额度”逐个查询支持的凭证，包含已停用账号。

只连接 `http://127.0.0.1:<端口>`；本版不支持远程管理地址、HTTPS 本地服务或自行读取其他程序保存的密钥。请在应用里输入密钥，不要提交到仓库或聊天。

**管理密钥在本机记住**：首次连接成功后，将管理端口与密钥一起保存到这台 Mac 的应用数据目录，不再使用钥匙串或触发其授权。更新或重启应用后自动恢复，只请求本机凭证列表，不自动刷新额度或调用模型。密钥不回填输入框，不进入日志、localStorage 或位置缓存。

- **断开连接**：只断开本次会话，保留本机记录，下次启动仍自动连接。
- **忘记密钥并断开**：删除本应用保存的本机连接，同时清空当前内存会话；不删除 CLIProxy 凭证。
- **更换密钥或端口**：填写后连接；仅在连接成功后替换保存记录，错误密钥不会覆盖原记录。
- **服务未启动或密钥失效**：保留本地记录并显示错误。服务恢复后，在连接窗口点击“使用本地记录重连”，或输入新密钥。
- **文件保存/读取失败**：明确显示错误。使用同目录临时文件和原子替换，保存失败保留原记录；记录损坏时保留文件并提示重新连接或忘记。

本地记录位于 `~/Library/Application Support/io.modellens.desktop/connection.json`，以明文 JSON 保存端口与密钥，目录权限 0700、文件权限 0600，仅当前用户可读写；应用不上传或同步该记录。它保存在应用数据目录，系统清理缓存不会让连接丢失。

**从使用钥匙串的 0.2.7–0.2.9 主线版本升级**：新版不访问、迁移或删除旧钥匙串条目，避免再次弹出系统授权。请在应用内重新输入一次密钥，连接成功后即使用本地文件。旧条目可自行在“钥匙串访问”中按 service `io.modellens.desktop.management`、account `local-connection` 删除；新版“忘记密钥”只删除本地文件。

关闭主窗口仅隐藏窗口；菜单栏右键 →“退出 ModelLens”才会退出。

## 凭证开关和额度

- 开关会立即影响 CLIProxy 后续路由，没有二次确认。写入时两窗口的相关操作均禁用。
- 写入前重新获取账号状态；若其他客户端已修改状态，停止本次操作并展示新状态。
- 写入成功、失败或超时后都尝试重新读取列表。结果不确定时提示核实；无法读取时禁用开关，直到手动刷新成功。不会自动重试写入或覆盖用户在其他客户端的操作。
- `runtime_only` 或缺少可靠开关字段的凭证显示为不可独立切换，由原服务管理。
- 额度刷新调用 CLIProxy 的管理代请求接口，由 CLIProxy 为指定 `auth_index` 注入 Token；ModelLens 不下载认证文件，也不取得厂商 Token。
- 仅访问固定厂商用量接口和 Gemini 只读项目信息接口，不发模型采样请求、不消费重置次数。
- 服务商的已用百分比转换为剩余百分比。缺失、非法或不支持的窗口显示“未提供”，不会当成 0%；月度窗口不会冒充 1w。
- 刷新失败保留上一次数据，并明确标注错误和更新时间。手动刷新单个或全部额度时包含停用账号；查询不改变账号开关，也不为查询临时启用。启动恢复仍不自动查询额度。
- 全部刷新为串行操作，每次请求最多等待 25 秒；大列表可能需要较长时间，期间不能切换或断开连接。当前没有单独的批量取消按钮，可退出 ModelLens 结束本地等待，不停止 CLIProxy。

菜单栏优先显示启用账号，有 5h 时显示 5h，否则优先 1w；新厂商的月度或模型额度按实际类型显示。同一优先级有多项时取最低已知剩余百分比，标记“最低”，悬浮可查看全部模型／周期；不会把未知项当成零。均无百分比时使用中性空条，不填充绿色或显示周期。额度失败只标记对应账号，底部汇总异常数量，不将单账号失败误报为管理连接失败。400×270 面板可完整显示四行，账号较多时仅列表内部滚动。点击外部或按 Esc 收起，主窗口按钮可打开完整卡片。

### Grok / Gemini 额度

| 凭证类型 | 展示范围 |
| --- | --- |
| xAI / Grok OAuth | 优先查询 credits 账单的周期总额度；没有有效总比例或请求失败时，回退到单独月度账单。按实际周期显示，未知周期标“周期”，不把月度转成 1w。有周额度时不额外拉取月度账单。产品消耗仅显示为共享额度已用占比，不计算产品独立余额。 |
| Gemini / Gemini CLI OAuth | `retrieveUserQuota` 返回的每个模型额度桶，展示实际剩余比例、可用数量和重置时间。缺少比例但有数量时，仅显示数量。 |
| Antigravity OAuth | `retrieveUserQuotaSummary` 返回的额度分组及实际 5h／1w 窗口。 |

- 这些账号启用、停用均可刷新。API Key 类型不使用 OAuth 额度接口；不支持的凭证会明确标记。
- Gemini 优先使用列表中的 `project_id`／`projectId`；缺失时通过 `loadCodeAssist` 只读获取。仍缺失时提示先在对应客户端完成登录／项目配置，不下载认证文件、不自动开通项目。
- 新厂商额度能力与模型探查能力分开，自动探查仍只支持 Codex / Claude OAuth。
- Grok 回退查询、Gemini 项目发现各最多增加一次请求，每次请求上限 25 秒；仅保存内存额度，失败保留上次成功值。真实服务兼容性未进行账号实测。
- Grok 新增单色图标，Gemini CLI 和 Antigravity 映射到已有 Gemini 星形图标，沿用现有深浅色规则。

## JSON 导入和删除

连接成功后切换到“凭证优先”，点击“导入 JSON”：

1. 选择一个 `.json` 文件，或填写文件名并粘贴 JSON；每次一个，最大 1 MiB。
2. 文件名不得含目录、控制字符或冒号，最多 240 字节；JSON 必须为含有效 `type` 字段的单个 CLIProxy 凭证对象，不接受数组或空对象。字段结构校验不代表厂商认证有效。
3. 点击“校验并导入”。通过本机管理接口上传，CLIProxy 保存并加载凭证；ModelLens 不把导入内容写入自己的文件、日志或浏览器存储。选择文件时不把文件内容展示到界面。
4. 导入前读取最新列表，发现同名则停止，包括大小写和 Unicode 规范化等价名称；请改名后重试。导入后核实新文件是否出现在列表中，不自动查询额度或调用模型，启用状态由导入内容和服务决定。

凭证卡片右下角垃圾桶按钮用于删除。弹窗显示账号和文件名，点击“确认删除”后从 CLIProxy 删除对应文件，影响后续路由；应用内无法撤销，请自行保留原文件。仅运行时凭证、非独立文件或多个账号共享同一文件时不允许删除。

删除前再次读取列表，检查身份、开关和文件元数据是否变化；变化则停止并要求重新确认。写入后重新读取列表，不能仅凭 HTTP 成功就报告导入或删除成功。超时、失败、核实不一致时不自动重试；无法读取列表时显示“待核实”，禁用后续写入，先手动刷新。

**并发边界**：CLIProxy 的上传/删除接口不提供原子“仅当不存在时创建”或版本条件写入。ModelLens 的最新列表检查能阻止已观察到的冲突，无法消除检查完成后其他客户端恰好修改同一文件的竞态；导入/删除时避免同时在其他管理客户端修改同名文件。

接口依据：[CLIProxy v8 路由](https://github.com/router-for-me/CLIProxyAPI/blob/main/internal/api/server_management_v8.go)、[官方管理接口说明](https://github.com/router-for-me/CLIProxyAPIDocs/blob/main/docs/en/management/api.md)。v8 使用 `POST/DELETE /credentials?name=…`，已有连接协商到 v0 时使用 `/auth-files?name=…`；文件名独立编码，写请求失败不会切换接口重发。

主窗口右上角设置 →「外观设置」，菜单栏底部调色图标也可直接打开。浅色、深色、跟随系统三种模式可切换；只改变 ModelLens，不改 macOS 系统偏好。主窗口和菜单栏同步，记住上次选择。

**主窗口、菜单栏、下拉框和弹窗均隐藏滚动条**，保留滚轮、触控板和键盘滚动；凭证列表和主面板可通过 Tab 聚焦，再用方向键 / Page Down / End 浏览。隐藏滚动条不会截断后续账号。

主题偏好仅保存模式与配色，不包含账号或密钥。管理密钥由独立的本地文件保存，更新应用后自动恢复连接。

## 下拉菜单、弹窗和动效

保留 09A 的字号与紧凑密度，使用当前所选主题，模型及凭证选择统一使用自定义下拉菜单，展示厂商图标、说明与选中标记。支持方向键、Home / End、首字母定位、Enter 选择、Esc 关闭和 Tab 离开；弹层接近窗口底部时向上展开。

连接、服务位置等弹窗统一标题栏、内容间距和操作区，支持 Esc、关闭按钮及点击遮罩退出。弹窗关闭动画结束后先关闭原生对话框、恢复原焦点，再移除界面。鼠标打开或关闭弹窗、收起下拉框不显示自动焦点描边；键盘导航与文本输入使用 120ms 柔和阴影，失焦后恢复。下拉展开和主题选中也不额外加描边。菜单栏中优先关闭当前下拉或弹窗，再由 Esc 收起窗口。

「检测提示词」与「原始回答与采样详情」取消悬浮底色和按下缩放，保留展开与箭头动效。手动回答框默认两行，可拖高和滚动。界面精简重复引导，保留未接入、操作失败、密钥保存与账号开关等必要说明。

按钮按下与悬停约 120ms，开关与弹层约 140–200ms，折叠区与分段选择约 220–240ms，主次布局约 220ms，额度条更新约 420ms。应用内动画始终启用，不随 macOS 的“减少动态效果”设置关闭；不修改系统偏好。未增加动效库。主次切换使用 WebView 的 View Transitions 对整个内容区做纯渐隐渐显，不做横向位移或宽度动画，避免真实内容每帧跟随列宽重排；不支持该能力的旧 WebView 使用短淡入。连续点击以最后一次选择为准。

自定义下拉采用系统 WebView 的 Popover API；不支持此 API 时回退系统原生选择框。当前面向本机 macOS 26，旧 macOS 的交互兼容性尚未实机验证。

## 自动发现与位置记忆

只检查当前用户的进程可执行路径，不读取完整命令行、环境变量、配置文件或认证目录。使用系统 `ps` 与 `lsof`，检查有超时限制。

识别程序名：`cliproxyapi`、`cli-proxy-api`、`cliproxy` 及对应 `-plus` 名称；另兼容 CLIProxy 项目目录下的 `cpa` 开发程序。无关目录中的同名 `cpa` 不会被自动认领。

- 普通程序的“所在目录”为可执行文件父目录。
- `.dev/cpa` 的项目目录按约定上移一级，真实工作目录单独保留。
- 无法读取工作目录时显示缺失；多个实例分别展示，不自动操作其中一个。
- 服务退出后仍保留历史位置；发现失败显示“状态未知”。
- 缓存损坏时保留原文件并提示，不静默覆盖。

位置缓存为 `~/Library/Application Support/io.modellens.desktop/discovery.json`，仅保存路径和时间，不将 PID 当成永久运行状态。目录权限 0700，文件权限 0600，以临时文件替换写入。

## 开发和构建

新工作区或编码助手接续时，先阅读 [AGENTS.md](AGENTS.md)，其中记录已确认设计、操作边界和当前交付状态。

技术栈：**Tauri 2 + Rust + React + TypeScript + Vite**。凭证网络操作在 Rust 中，前端只接收白名单字段；不新增服务器或数据库。

前置环境：macOS、Xcode Command Line Tools、Node.js 24、pnpm 10.10.0、Rust 1.89。依赖由 `pnpm-lock.yaml` 和 `src-tauri/Cargo.lock` 锁定。

```sh
git clone https://github.com/xieyuqiyu-source/model-lens.git
cd model-lens
pnpm install --frozen-lockfile
pnpm desktop        # 桌面开发，发现真实本机进程
pnpm dev            # 仅浏览器 UI，不能操作本机管理接口
pnpm check          # TypeScript 与 Rust 编译检查
pnpm test:ui        # 弹层、动画、探查内核对照及采样状态自检
pnpm test           # 合成数据和本机模拟 HTTP 服务测试
pnpm package        # 生成当前 Mac 架构的 Release .app
```

探查集成回归：启动 `pnpm dev` 后运行 `uv run --with playwright python tests/browser-probe.py`，使用合成 IPC 回答，不访问真实账号。
凭证管理浏览器回归：在独立端口启动 `pnpm dev --port 1421`，运行 `uv run --with playwright python tests/browser-credentials.py`。脚本注入合成 IPC，不访问真实服务，覆盖启停账号查询、导入、删除、冲突、失败与菜单栏；可通过 `MODEL_LENS_TEST_URL` 指定本地测试地址。

弹窗焦点浏览器回归：启动 `pnpm dev` 后运行 `uv run --with playwright python tests/browser-focus.py`。首次使用需通过 `uv run --with playwright playwright install chromium webkit` 安装测试浏览器；脚本仅访问本地 UI，不连接真实管理服务。

开发服务器仅绑定 `127.0.0.1:1420`；端口占用时失败，不自动结束占用进程。前端支持 Vite HMR，Rust 修改由 Tauri 开发流程重建。重新打包不会替换正在运行的应用，需退出 **ModelLens** 后再打开新版；CLIProxy 无需重启。

## 数据与安全

- 不自动扫描现有认证文件、CLIProxy 配置、DSH 密钥或浏览器凭据；导入仅读取用户在应用中选择或粘贴的 JSON。
- 网络客户端固定为回环地址，不使用系统代理，不跟随重定向，限制响应体大小和等待时间。
- 列表仅向 UI 投影账号名、厂商、状态等字段；丢弃 `account`、Token、文件路径和未经筛选的上游内容。错误只显示固定说明或 HTTP 状态码。
- 管理密钥与本机端口以明文保存于本机专用文件，权限 0600，应用不启用云同步；凭证列表和额度不持久化，窗口偏好使用 WebView localStorage。
- 不修改代理、服务绑定、进程启停或额度重置；凭证文件导入/删除仅由用户明确操作触发。没有遥测、云同步和用户登录系统。
- 真实开关会影响账号是否参与服务路由。开发测试使用模拟服务，不自动切换真实账号。

## 更新和卸载

更新：拉取代码、安装锁定依赖、重新打包，退出 ModelLens 后替换 `.app`。关闭或退出 ModelLens 都不停止 CLIProxy。

卸载：如需删除保存的管理密钥，先在连接窗口点击“忘记密钥并断开”，再退出 ModelLens 并移除 `.app`。仅删除 `.app` 不会删除本地连接文件。如需清除本地连接和记住的位置，可自行移除上述应用数据目录。0.2.7–0.2.9 主线版本遗留的钥匙串条目需自行在“钥匙串访问”中删除。界面偏好属于系统 WebView 网站数据。本项目不会自动删除真实认证文件或上游数据。
